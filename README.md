# Axomic Prometheus-Deobfuscator

made by axom
has renamer built-in too

## CLI

```bash
node deobfuscator.js input.lua -o clean.luau
node deobfuscator.js input.lua --ms
node deobfuscator.js input.lua --rename
node deobfuscator.js ms rename input.lua -o clean.luau
node ../deobfuscator_before_split.js input.lua -o clean.luau
```

## Web

```bash
node deobfuscator.js web --host 0.0.0.0 --port 8765
```
